# Easy Proxies v1.9

## English

- Hardened manual source refresh with mandatory snapshots, full rollback on cancellation or infrastructure failures, and explicit partial-completion reporting.
- Added live completed/total progress for every probe round in both source-refresh and regular node-test dialogs.
- Added child-task timeout cancellation and cleanup so timed-out refreshes do not continue modifying nodes in the background.
- Serialized runtime reloads and configuration mutations to prevent overlapping sing-box lifecycle operations.
- Made managed-node persistence ordered and transactional while keeping reads responsive during disk writes.
- Propagated node removal, promotion, persistence, and reload failures instead of reporting false success.
- Unified single-node manual tests with the resilient asynchronous three-round test workflow.

## 简体中文

- 强化手动刷新导入来源：启动前强制创建快照，取消或基础设施异常时完整回滚，并明确显示部分完成状态。
- 导入来源刷新和普通节点测速弹窗均增加每轮已完成数、总数和剩余数的实时进度。
- 增加子任务超时取消与清理，避免父任务结束后仍在后台修改节点。
- 串行化运行时重载和配置变更，避免 sing-box 生命周期操作重叠。
- 节点数据持久化改为有序事务写入，同时保持磁盘写入期间的读取响应。
- 节点删除、入池、保存和重载失败会向上返回，不再显示错误的成功状态。
- 单节点手动测速统一使用带回滚保护的异步三轮检测流程。
