# Easy Proxies v1.7

## English

- Added local backup import/export for subscriptions, imported nodes, and application settings.
- Added WebDAV connection testing, timestamped remote backups, backup listing, restore, and configurable remote folders with `/easy_proxies` as the default.
- Added Tag-based node data export with single, multiple, or all-Tag selection while preserving each source's applicable export representation.
- Expanded "Retest all import sources" to cover every tagged source, including subscription URLs, URI lists, Clash YAML, and Base64 imports.
- Reworked source refresh into a bounded concurrent scheduler so a slow subscription no longer blocks healthy sources.
- Added hard per-source deadlines, bounded pool-proxy fallback, prioritized healthy proxy candidates, deferred final retries, and saved-node fallback when a subscription cannot be fetched.
- Added detailed direct, proxy, retry, cached-node, testing, and promotion progress to the WebUI.
- Added refresh cancellation in the API and WebUI; closing the progress dialog keeps the task running, while "Cancel test" stops it explicitly.
- Fixed canceled imports leaving nodes permanently in the `testing` state and added startup recovery for stale persisted test states.
- Redacted full subscription URLs and tokens from refresh errors shown in the WebUI.
- Added concurrency, timeout, cancellation, state-recovery, proxy-candidate, and privacy regression coverage.

## 简体中文

- 增加本地备份导入、导出，覆盖订阅、已导入节点和应用设置。
- 增加 WebDAV 连接测试、时间戳远程备份、备份列表、恢复功能和可配置远程目录，默认目录为 `/easy_proxies`。
- 增加按 Tag 导出节点数据，支持单个、多个或全部 Tag，并按各来源适用的表达形式导出。
- “重新检测全部导入来源”扩展为覆盖所有带 Tag 的来源，包括订阅 URL、URI 列表、Clash YAML 和 Base64 导入。
- 将来源刷新重构为有界并发调度，慢订阅不再阻塞其他正常来源。
- 增加单来源硬超时、有限节点池代理兜底、健康候选优先、失败来源延后重试，以及订阅拉取失败后的保存节点检测兜底。
- WebUI 增加直连、代理尝试、等待重试、缓存节点、节点检测和加入节点池等详细进度。
- API 和 WebUI 增加刷新取消功能；关闭进度弹窗时任务继续在后台运行，点击“取消检测”才会明确终止。
- 修复取消导入后节点永久停留在 `testing` 状态的问题，并在启动时恢复历史遗留的检测状态。
- WebUI 刷新错误不再显示完整订阅 URL 和令牌。
- 增加并发、超时、取消、状态恢复、代理候选和隐私相关回归测试。
