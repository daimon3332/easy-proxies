# Easy Proxies v1.8

## English

- Added three-round node probing: failed nodes are deferred until the remaining queue finishes, retried against both supported probe targets, and delayed by one second between rounds.
- Added a shared concurrency limit and adaptive retry concurrency to prevent concurrent sources from overwhelming the service while keeping large retry queues fast.
- Kept the configured probe timeout for every round instead of extending later attempts, reducing worst-case refresh time.
- Added live probe round, pending count, target, and concurrency details to refresh progress.
- Added snapshots, rollback, and circuit breakers for canceled, failed, or abnormally destructive bulk refreshes.
- Added staged subscription replacement so existing nodes remain available until the refreshed source completes testing.
- Aligned the final success count with the actual available port count while retaining the raw probe-passed count in task details.

## 简体中文

- 增加三轮节点探测：失败节点延后到当前队列完成后重试，覆盖两个受支持的探测目标，每轮间隔一秒。
- 增加全局并发限制和自适应重试并发，避免多个来源同时检测压垮服务，并保持大失败队列的处理速度。
- 三轮统一使用已配置的探测超时，不再逐轮延长，缩短最坏情况下的刷新耗时。
- 刷新进度增加当前轮次、待测数量、探测目标和并发数。
- 批量刷新增加快照、回滚和熔断保护，覆盖取消、异常和结果异常恶化等情况。
- 订阅刷新使用临时节点完成测试后再替换，检测期间继续保留原有可用节点。
- 最终成功数量与实际可用端口数量保持一致，同时在任务详情保留原始探测成功数。
