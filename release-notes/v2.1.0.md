# Easy Proxies v2.1.0

## English

- Added a shared sing-box probe runtime to reduce repeated runtime construction during node testing and retries.
- Added bounded asynchronous probe scheduling with delayed retries, alternate probe targets, and cross-job de-duplication.
- Pooled nodes are now verified through their actual local multi-port listener after the shared outbound probe succeeds, preventing false-positive available ports.
- Added support for authenticated runtime-listener verification and normalized wildcard listen addresses for local validation.
- Unified tagged source refresh behavior across subscription URLs, URI, YAML, and Base64 imports while preserving source references for shared nodes.
- Added bounded job persistence, SQLite state updates, incremental runtime reconciliation, paged WebUI queries, SSE progress updates, bounded caches, and localhost-only optional pprof diagnostics.
- Added regression coverage for listener failures, authentication, source ownership, runtime reconciliation, bounded scheduling, persistence rollback, and diagnostics security.
- Release packages are provided for Windows and Linux only. Each platform includes amd64 and arm64 binaries and ZIP packages.

## 简体中文

- 新增共享 sing-box 测速运行时，减少节点测速和重试过程中的重复运行时创建。
- 新增有界异步测速调度、延迟重试、备用探测目标和跨任务去重。
- 共享 outbound 测速成功后，节点还必须通过实际的 multi-port 本地端口验证，避免出现测速成功但可用端口不可用的假阳性。
- 支持带认证的真实端口验证，并自动规范化通配监听地址，确保本机验证使用正确的回环地址。
- 统一订阅 URL、URI、YAML 和 Base64 导入来源的 Tag 刷新流程，同时保留共享节点的多来源引用关系。
- 增加有界任务持久化、SQLite 状态增量更新、运行时增量协调、WebUI 分页查询、SSE 进度更新、有界缓存和仅限本机的可选 pprof 诊断。
- 增加真实端口失败、认证、来源归属、运行时协调、有界调度、持久化回滚和诊断安全相关回归测试。
- 本版本仅提供 Windows 和 Linux，分别提供 amd64、arm64 二进制文件及 ZIP 压缩包。
