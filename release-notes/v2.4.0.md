## What's Changed

- Added per-tag front-proxy management in Settings. A front proxy can now be assigned, changed, or removed for one tag, selected tags, or every imported tag.
- Front-proxy binding changes run as resumable background jobs with per-tag progress, cancellation, and failure isolation. Existing routes and ports remain unchanged when a replacement route does not pass verification.
- The import page now preserves the selected front proxy across imports and restores a tag's existing binding when that tag is reused.
- Import sources now report direct, profile, and mixed front-proxy bindings so shared nodes and multi-source tags remain distinguishable.
- Outlook verification now checks both the requested Outlook page and the Microsoft sign-in endpoint, preventing a partially usable route from being reported as fully available.
- Fixed successful imports failing at the final apply step when stale runtime ports remained after all persisted nodes had been deleted. Runtime configuration is reconciled with the persisted pool before staged results are promoted.
- Made "Delete all" transactional. Configuration deletion, runtime reload, persisted-node deletion, verification, and rollback now fail explicitly instead of leaving hidden listeners behind.
- Added a management-only empty-pool state. Easy Proxies can start and keep the WebUI available with zero nodes, releases all proxy listeners when the final node is removed, and starts the proxy runtime again when nodes are added.
- Added regression coverage for per-tag binding, shared routes, failed binding rollback, empty-pool startup and restart, orphan runtime cleanup, and transactional source deletion.
- Release packages are provided for Windows and Linux. Each platform includes amd64 and arm64 binaries and ZIP packages, plus SHA-256 checksums.
