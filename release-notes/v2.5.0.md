## What's Changed

- Redesigned the WebUI with a grouped, collapsible sidebar, a breadcrumb top bar, and a refreshed light visual style across every page.
- Added a dashboard as the default page, showing pool, candidate, failed, and testing counts, node composition, subscription refresh status, runtime diagnostics, import sources, and live job progress.
- Node tables now use a single toolbar with segmented sorting, a port reorder menu, and an auto-probe menu. Bulk actions appear only when nodes are selected, and the selected count updates immediately.
- Import formats are switched inline without a dialog, and the pasted content is kept when switching formats.
- The import page now stacks the import form above the local port list, which uses the full page width.
- Split the embedded WebUI into separate HTML, CSS, and JavaScript files served from `/assets/` with revalidation, so upgrades take effect without a stale browser cache.
- Only one process can use a given config file. A new process waits up to 40 seconds for the previous instance to exit, preventing duplicate instances from shifting ports or writing shared data.
- The program now exits with a clear error when the management port is already in use instead of running without a WebUI.
- Config and node list files are written atomically, so an interrupted write no longer leaves a truncated `config.yaml`.
- Multi-port mode no longer resolves GeoIP for every node or starts an unused GeoIP router, reducing startup and full reload time from several seconds to under one second on large pools.
- The embedded Clash API is disabled by default. Set `EASY_PROXIES_CLASH_API_LISTEN` (for example `127.0.0.1:9092`) to enable it.
- Completed import jobs are pruned while running instead of only at startup, and running probes no longer poll for cancellation, lowering idle and probing CPU usage.
- Applying site check results no longer fails as a whole when a single qualifying node cannot produce a runtime configuration. Such nodes are moved to the failed list with the reason, and the remaining ports are applied.
- Added management server header and idle timeouts.
- Simplified the README and user guide, replaced the screenshots, and removed the Traditional Chinese documents.

## Downloads

Windows and Linux builds are available for amd64 and arm64, with standalone binaries, ZIP packages, and SHA-256 checksums. Existing configuration files remain compatible.
