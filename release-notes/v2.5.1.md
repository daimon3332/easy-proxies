## What's Changed

- Fixed imports and refreshes failing as a whole with "1 runtime port unavailable". When a generated name suffix matched another node's real name (for example two "Edge" nodes and one "Edge-2"), two nodes received the same internal tag and one listener was silently dropped. Every node now gets a unique tag, so every pooled node gets its listener.
- Applying site check results no longer fails as a whole when a single qualifying node cannot produce a runtime configuration. Such nodes are moved to the failed list with the reason, and the remaining ports are applied.
- The import page now stacks the import form above the local port list.

## Downloads

Windows and Linux builds are available for amd64 and arm64, with standalone binaries, ZIP packages, and SHA-256 checksums. Existing configuration files remain compatible.
