## What's Changed

- Added reusable front-proxy profiles for chained routes. Front proxies can use any proxy URI supported by the current sing-box build and can be added, tested, edited, disabled, or removed from the import and settings pages.
- Imported nodes can now be tested and exposed through the complete `front proxy -> imported node -> target` route. Front-proxy baseline latency and complete-chain results are reported separately, while incompatible TCP/UDP protocol combinations fail with explicit errors.
- Added Host:Port list imports. Each batch can be interpreted as HTTP or SOCKS5, accepts `host:port` and optional `user:pass@host:port` entries, and supports text-file input.
- Added site connectivity checks for tagged routes against Google, GitHub, Outlook, and ProxySpace. Users choose the tested sites and tags, with Outlook selected by default.
- Site filtering uses the strict intersection of the selected sites. Detection never changes ports automatically: the WebUI shows the successful and failed routes plus the projected port impact before an explicit apply confirmation.
- Added exact-scope history comparison by route identity, stale-preview protection, shared-tag retention, stable ports for retained routes, and rollback when runtime application fails.
- Fixed non-qualifying site results remaining in the candidate set. After confirmation, qualifying routes enter the pool and selected non-qualifying routes enter the failed set with a site-specific reason.
- Improved the desktop WebUI with clearer settings columns, larger controls, localized states, bounded previews, compact batch tools, accessible dialogs, and a simplified connectivity result hierarchy.
- Backups now preserve chain profiles and chained-node references. Added regression coverage for chain construction, Host:Port parsing, site checks, history comparison, explicit pool application, rollback, and monitor APIs.
- Release packages are provided for Windows and Linux. Each platform includes amd64 and arm64 binaries and ZIP packages, plus SHA-256 checksums.
