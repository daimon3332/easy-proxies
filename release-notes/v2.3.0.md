## What's Changed

- Import testing and source refreshes can now use the configured 204 probe, any selected site checks, or site checks alone. Available targets include Google, GitHub, Outlook, and ProxySpace.
- Automatic subscription refreshes persist and reuse the same verification policy, while manual jobs report 204 rounds and per-site progress separately.
- Combined verification applies the selected site checks only to nodes that pass the 204 stage. A node must pass every selected check before it can enter the available pool.
- All 204 retry rounds now use the probe target selected in Settings instead of silently switching between Google and Cloudflare.
- Completed import and refresh jobs are retained for 10 minutes, site-check jobs for 30 minutes, and expired results are removed periodically without affecting active jobs or available ports.
- The WebUI now releases event streams, timers, and pending requests when the page is unloaded, reducing long-running resource usage.
- Refined the desktop WebUI with a clearer information hierarchy, larger controls, consistent spacing, fewer redundant descriptions, and a compact GitHub entry in the sidebar.
- Added regression coverage for verification-policy validation, site-only and combined checks, automatic refresh propagation, job cleanup, diagnostics, and WebUI behavior.
- Added a standalone proxy-audit utility for duplicate endpoint analysis and exit-country summaries without exposing proxy credentials in its reports.
- Release packages are provided for Windows and Linux. Each platform includes amd64 and arm64 binaries and ZIP packages, plus SHA-256 checksums.
