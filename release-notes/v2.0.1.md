# Easy Proxies v2.0.1

## English

- Fixed valid three-round probe failures being misclassified as a system-wide test anomaly and rolling back successful results from unrelated sources.
- Made the applied success count match the final available-port count after a completed source refresh.
- Retest saved nodes when every newly fetched subscription node fails, while keeping technical failures and cancellation transactionally recoverable.
- Replaced the global source-retry barrier with a bounded delayed queue: first attempts keep priority, failed URLs retry after one second in the next free source slot, and unrelated long-running sources no longer block retries.
- Preserved global probe concurrency limits and stopped dispatching new source work immediately after cancellation.
- Fixed the refresh-details dialog jumping back to the top during progress polling.
- Improved source-refresh labels by separating URL fetch attempts from node probe rounds.
- Refined Settings source cards with Tag-first ordering, colored type/count badges, clearer failed-before-candidate ordering, and wrapping highlighted source addresses.

## 简体中文

- 修复三轮测速失败被误判为全局检测异常，导致其他来源的成功结果一并回滚的问题。
- 刷新完成后，已应用的成功数量与最终可用端口数量保持一致。
- 订阅新节点全部失败时自动重新检测保存节点，同时继续为技术故障和用户取消保留事务回滚。
- 使用有界延迟队列替代全局来源重试屏障：首次任务优先，失败 URL 在一秒后占用下一个空闲来源槽位重试，不再等待无关的大型来源结束。
- 保持全局节点测速并发上限，并在取消后立即停止派发新的来源任务。
- 修复刷新详情弹窗在轮询进度时自动跳回顶部的问题。
- 区分订阅 URL 拉取尝试与节点三轮测速，避免轮次含义混淆。
- 优化设置页导入来源卡片：Tag 前置、类型和统计数据使用彩色标签、失败数量前置，并为来源地址增加可换行的高亮样式。
